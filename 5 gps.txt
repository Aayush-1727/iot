STEP 1 :- (Create a virtual environment)
1)	Installing the venv module:sudo apt install python3-venv
2)	Creating a  new virtual environment. myenv is user-defined name: python3 -m venv myenv
3)	Activate the Virtual Environment : source myenv/bin/activate
4)	It should look like :- (myenv) pi@raspberrypi:- $
(If virtual environment is already created just activate the environment)
